# P3 – Feature Branch Git Workflow

## Objective
To understand and practise the feature branch workflow using Git.

## Steps Performed

1. Checked the current branch using `git branch`.
2. Created a new feature branch using `git checkout -b feature/about-section`.
3. Modified the About Me section in the portfolio's HTML file.
4. Checked changes using `git status`.
5. Staged changes using `git add`.
6. Committed changes using `git commit`.
7. Pushed the feature branch to GitHub.
8. Switched back to the main branch.
9. Merged the feature branch into main using `git merge`.
10. Pushed the merged changes to GitHub.

## Commands Practised

| Command -- Purpose |
| `git branch` -- Lists branches |
| `git checkout -b` -- Creates and switches to a branch |
| `git add` -- Stages changes |
| `git commit` -- Saves changes |
| `git push` -- Uploads changes to GitHub |
| `git merge` -- Combines branches |

## Result
Successfully created a feature branch, made changes, committed them, pushed the branch, and merged it into the main branch.
